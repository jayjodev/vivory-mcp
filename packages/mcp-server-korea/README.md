# vivory-mcp-korea (discontinued)

<!-- mcp-name: io.github.jayjodev/vivory-mcp-korea -->

**This package no longer works and has no replacement.** It called the hosted
Vivory API (`api.vivory.app`), which was shut down on **2026-08-09**. The
package was removed from PyPI earlier. Its sibling `vivory-mcp-verification`,
which earlier versions of this README pointed to, is discontinued as well, and
there is no paid plan.

Please remove this server from your MCP client configuration. The source below
is kept only as a historical record.

이 패키지는 동작하지 않으며 대체품도 없습니다. 호출하던 API(`api.vivory.app`)가
2026-08-09 에 종료되었습니다. MCP 클라이언트 설정에서 지워 주세요.
